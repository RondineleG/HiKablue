# Agent Skills

Skills are reusable, task-triggered checklists. They supplement `.agc/RULES.md`; they do not replace mandatory rules and are not executable commands.

| Skill | Use when |
|---|---|
| [`vpn-lab-safety`](vpn-lab-safety/SKILL.md) | Designing, running, reviewing, or documenting TUN/UDP lab networking. |
| [`initial-tun-verification`](initial-tun-verification/SKILL.md) | Implementing or verifying the initial TUN task and its learning materials. |
| [`vpn-security-review`](vpn-security-review/SKILL.md) | Reviewing security boundaries, packet handling, key lifecycle, privileges, secrets, or dependencies. |

Keep this catalog small. Add a skill only for a repeated workflow with a clear trigger and reusable steps. Add executable commands alongside the project scaffold, not as a substitute for a skill.
